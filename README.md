# AI w praktyce – materiał szkoleniowy

Interaktywny materiał szkoleniowy do zajęć:

**„Nowe kompetencje cyfrowe w praktyce: Praktyczne wykorzystanie sztucznej inteligencji”**

## Zawartość

Strona zawiera m.in.:

- podstawowe zasady korzystania z AI,
- schemat dobrego promptu,
- generator promptów,
- przykłady: słaby → lepszy → bardzo dobry prompt,
- gotowe prompty do pracy urzędowej,
- przykłady pracy z PDF, Word i Excel,
- katalog narzędzi AI,
- zasady bezpieczeństwa i anonimizacji,
- checklistę weryfikacji odpowiedzi,
- 5 promptów, które warto zapamiętać.

## Uruchomienie lokalne

Nie trzeba nic instalować.

1. Pobierz repozytorium.
2. Otwórz plik `index.html` w przeglądarce.

Strona działa jako statyczny HTML i nie wymaga serwera.

## Publikacja przez GitHub Pages

1. Utwórz nowe repozytorium na GitHubie.
2. Wgraj zawartość tej paczki.
3. Wejdź w:
   `Settings → Pages`
4. W sekcji **Build and deployment** wybierz:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Zapisz ustawienia.

Po chwili GitHub udostępni publiczny adres strony.

## Uwagi

Materiał został przygotowany jako pomoc szkoleniowa.  
Przykłady dotyczą praktycznego i odpowiedzialnego wykorzystywania narzędzi sztucznej inteligencji.

Przed wykorzystaniem AI w pracy należy stosować zasady bezpieczeństwa informacji, ochrony danych i procedury obowiązujące w danej organizacji.
